# Software Implementation

This folder contains the software development and machine learning components of the Smart Water Quality Monitoring System.

## Technologies Used
- Arduino IDE
- Embedded C/C++
- Python
- Flask
- Machine Learning
- MQTT Protocol
- ThingSpeak Cloud Platform

## Main Software Components
- ESP32 sensor data acquisition
- Water Quality Index (WQI) calculation
- Machine learning-based water quality classification
- Cloud data transmission and monitoring
- Web-based dashboard and notifications
